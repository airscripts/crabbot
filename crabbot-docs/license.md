# License

Crabbot uses the Apache License 2.0.

Apache-2.0 keeps the project permissively open source while adding an express
patent grant, clear conditions for redistribution, and explicit protection for
contributors. Those terms fit a Rust runtime that is intended to be embedded,
extended with plugins, and shipped by both individuals and organizations.

MIT would also permit broad reuse, but it has no express patent license. A
copyleft license would require stronger reciprocity from downstream projects
and would make proprietary integrations less practical. Apache-2.0 is the
better default for Crabbot's interoperability goals.

The repository includes the full [LICENSE](../LICENSE), a [NOTICE](../NOTICE)
file, SPDX metadata in every Cargo manifest, and no CLA or DCO requirement.
Contributions are accepted under the repository license unless a separate
written agreement says otherwise.
